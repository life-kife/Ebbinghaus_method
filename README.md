# Карточки — Android-приложение интервального повторения

Приложение для запоминания по методу Эббингауза: карточки «вопрос — ответ», расписание повторений по алгоритму SM-2 и уведомления на телефоне в дни, когда пора повторять. Уведомления приходят, даже если приложение закрыто и телефон перезагружали.

Технологии: HTML/CSS/JavaScript + Capacitor 6 (обёртка в Android-приложение) + плагины Local Notifications, Haptics, App, Status Bar. Шрифты Golos Text и Literata встроены в приложение, интернет не нужен.

## Что умеет версия 1.1

- Знакомство при первом запуске: три экрана и выбор времени напоминаний.
- Экран «Сегодня»: прогресс за день, серия дней подряд, неделя занятий, колоды с цветными метками.
- Повторение с переворотом карточки и вибрацией при ответе, итоги после сессии.
- Поиск и фильтр по колодам, создание и редактирование карточек в нижней панели.
- Своя иконка и заставка, системная кнопка «Назад», цвет строки состояния под тему.

## Структура

```
www/index.html                    — всё приложение: интерфейс, SM-2, уведомления
www/fonts/                        — встроенные шрифты
assets/                           — исходники иконки и заставки
keystore/debug.keystore           — постоянный отладочный ключ подписи, чтобы обновления ставились поверх
capacitor.config.json             — имя и идентификатор приложения
.github/workflows/build-apk.yml   — автоматическая сборка APK на GitHub
```

## Скачать готовый APK

https://github.com/life-kife/Ebbinghaus_method/releases/latest/download/kartochki.apk

Ссылку можно открыть прямо на телефоне. Файл обновляется автоматически после каждого изменения в репозитории.

## Способ 1. Собрать APK на GitHub (без установки программ)

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Создайте новый репозиторий: кнопка **New**, имя например `kartochki`, тип **Public** или **Private**, без README.
3. На странице пустого репозитория нажмите **uploading an existing file** и перетащите туда **содержимое** распакованной папки (папки `www`, `.github` и файлы `package.json`, `capacitor.config.json`, `README.md`, `.gitignore`). Нажмите **Commit changes**.
   - Папка `.github` начинается с точки. В Windows она видна в Проводнике, просто перетащите её вместе с остальными.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут. Если GitHub попросит подтвердить запуск workflow, нажмите кнопку подтверждения.
5. Когда появится зелёная галочка, откройте эту сборку и внизу в разделе **Artifacts** скачайте `kartochki-apk`. Внутри zip-архива лежит `app-debug.apk`.

## Способ 2. Собрать в Android Studio

1. Установите Node.js 18+ и Android Studio.
2. В папке проекта выполните:
   ```
   npm install
   npx cap sync android
   npx cap open android
   ```
3. В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**, либо подключите телефон по USB и нажмите **Run**.

## Установка на телефон

1. Перекиньте `app-debug.apk` на телефон (через кабель, Telegram «Избранное», облако).
2. Откройте файл. Android попросит разрешить установку из этого источника: разрешите.
3. Google Play Защита может предупредить о неизвестном разработчике: это нормально для своей сборки, выберите «Всё равно установить».
4. При первом запуске разрешите уведомления.

## Что проверить

- **Главная**: число карточек на сегодня и кнопка «Начать повторение».
- **Повторение**: «Показать ответ», затем оценка. Под кнопками видно, когда карточка вернётся.
- **Ещё → Напоминания → «Проверить»**: сверните приложение, через 10 секунд придёт уведомление. Нажатие на него открывает повторение.
- **Ещё → Напоминания**: выберите время, например через пару минут от текущего, закройте приложение полностью и дождитесь уведомления.
- **Ещё → Для проверки прототипа**: перемотка даты, чтобы увидеть, как карточки возвращаются через дни.

## Если уведомления не приходят

- Проверьте, что уведомления для приложения включены: Настройки → Приложения → Карточки → Уведомления.
- На Xiaomi, Huawei, Honor, Samsung включите для приложения **автозапуск** и снимите **ограничения экономии батареи** («Без ограничений»). Эти оболочки могут задерживать или блокировать фоновые уведомления.

## Ограничения прототипа

- Данные хранятся в памяти встроенного браузера приложения. При удалении приложения или очистке его данных карточки пропадут. Для резервной копии используйте «Ещё → Сохранить копию карточек».
- Это отладочная сборка (debug), для публикации в Google Play нужна подписанная release-сборка.
- Следующие шаги: база SQLite (плагин `@capacitor-community/sqlite`), история повторений, редактирование карточек, импорт файлов Anki.
